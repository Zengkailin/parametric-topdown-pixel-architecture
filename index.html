内描边只画在该部件自己的像素上（轮廓、折面断层、部件分界，向内部加粗）；部件交界处只由一侧拥有（更靠前/指定侧），不会两边各画一条合成 2px 粗缝。部件外描边把每个部件的剪影向外扩，允许压到别的部件上，但只允许“前侧压后侧”；重叠处覆盖率更高者赢，其次更近，再次更靠前。轮廓描边只把整栋建筑的剪影外扩到背景上。三者宽度都按输出像素连续计算：关抗锯齿时 0.5 是 50% 混色/半透明的 1px 线、1 才是实色 1px；0 为关闭。

正交投影没有消失点；透视投影会随 FOV 产生消失点。FOV 0° 是透视的极限——相机距离趋于无穷，等价于正交投影，工具会自动按正交出图并标注「正交极限」。
俯角只改变看见立面与屋顶的比例：90° 即纯顶视，0° 为平视（纯立面）。
自适应画布会按像素密度与建筑投影范围自动计算宽高；固定像素密度则 1 米 = 指定像素。

说明

本工具只保留几何 + 材质：不计算日光、阴影、环境光，也不做色调映射。 明暗完全来自材质图集本身的像素笔触，因此输出稳定、可批量复现。
参数语义与 Godot 插件 topdown_building_studio 一致（网格单位：米，+Z 为正面）。
预览里点击任意部件可查看它引用的纹理，并单独染色、替换贴图或设置部件级描边（只作用于当前建筑）。

导出 Godot 预制体

纯内置节点

导出 ZIP：一张裁到不透明边界（+留边）的 PNG，以及引用它的 .tscn。 节点结构为 StaticBody2D + CollisionPolygon2D + Sprite2D + 遮挡层 Area2D，不含任何脚本与 StippleShadow。

碰撞层 = 地基投影；遮挡层 = 不透明覆盖扣除碰撞区后、基点（地基中心）以上每块的外轮廓。
只导出当前预览方向；纯色背景会拒绝导出。ZIP 按 res:// 目录结构打包，解压到工程根目录即可。

ZIP 内路径与上面的 res:// 一一对应；.tscn 内的贴图路径可随时在 Godot 里改。

建筑材质贴图规范 · 参数说明

1. 图集格式（推荐）

  • 一张正方形 PNG，边长能被 4 整除（建议 512 或 1024，即 128 或 256 像素一格）。
  • 4 × 4 = 16 格，顺序固定（与插件的 building_materials_v5.gd / building_materials_v6.gd 一致）：
行 1roof 屋顶瓦wood 木构件wall 墙面stone 石作
行 2trim 饰条glass 玻璃cloth 布幔metal 金属
行 3shadow 内影accent 点缀door 门扇window 窗扇
行 4roof_edge 瓦口wall_base 墙裙sign 招牌shutter 百叶
  • 可平铺角色（除 door/window/sign/shutter/wall_base/roof_edge 外）：应能无缝四方连续，工具会自动把首尾像素取平均以消除接缝。
  • 构件角色：整格使用，请把主体画满整格（门、窗、招牌、百叶建议留极窄边或直接满幅）。
  • 透明像素按“无材质”处理（会露底），因此请把 alpha 补齐；贴图内部禁止大面积透明。
  • 运行时按最近邻采样，绝不做双线性/平滑插值：roof 格统一到 64px，其余统一到 128px。 例如 256×256 图集 = 64px/格：屋顶 1:1，其余 2× 最近邻放大（每个源像素变成 2×2 色块，不会变模糊）； 512×512 图集 = 128px/格：其余 1:1、屋顶 2× 缩小；1024×1024 = 256px/格：全部 2× 缩小。
  • 只有两处会产生“平均色”，都是插件同款的预滤波：一是可平铺角色最外圈 1px 的接缝混合；二是缩小时按 mip 层级最近邻取样（等价 NEAREST_WITH_MIPMAPS）。放大时永远取 mip 0，不会模糊。
  • 如果画面偏软，先关掉「抗锯齿」——那是 2× 超采样后盒式降采样，会平均边缘像素；材质放大本身不模糊。

2. 逐角色贴图（可选）

  • 也可以为单个角色单独上传一张正方形 PNG（同样会被缩到 64 / 128），用于替换图集中对应格。
  • 未上传的角色优先取图集对应格；既无图集也无单图时，用调色板按插件 v3 的像素配方程序化生成。
  • 预览里点中部件后，检查器的「替换纹理」可上传单张 PNG；「从纹理库选择」会把当前所有已导入的纹理（内置风格 + 自定义风格）里同一角色的贴图列出来， 点一下即换成那个风格的同部件贴图（最近邻缩放到 64 / 128，与图集同规则），只作用于当前建筑并写入配方 JSON 的 parts.<角色>.textureFrom。

4. 部件检查器（点击拾取）

  • 在预览里点击任意部位：渲染时会写一张“角色索引”拾取缓冲，直接告诉你这块面用的是哪个材质角色 （roof / wood / wall / stone / door…）。
  • 检查器显示该部件当前引用的纹理缩略图与来源：风格图集第几行第几列、风格单角色图、程序化调色板、或部件覆盖。
  • 单独染色：颜色与纹理相乘，保留像素细节；替换纹理：上传正方形 PNG， 按与图集相同的规则最近邻缩放到 64 / 128。
  • 部件级描边：检查器里的「内描边 / 外描边」各有「继承」开关。默认继承面板上的全局宽度与颜色； 取消继承后可单独设宽度和颜色，覆盖全局。部件外描边是「这个部件向外扩一圈」， 可以压到相邻部件上，和「轮廓描边（整栋剪影外扩到背景）」是两件事。
  • 覆盖只作用于当前建筑，不改动风格；会参与导出，写入 recipe.json 的 parts， 并随配置保存。检查器「重置」把当前部件的染色 / 贴图 / 描边恢复为初始状态；舞台栏「重置全部部件」一键清空。
  • 点击 1px 细边或被描边盖住的位置时，会自动在 2px 邻域找最近部件；点击背景取消选中。

5. 与插件的差异（有意为之）

  • 不计算光照：无日光、阴影、环境光、色调映射。材质图集本身负责明暗。
  • 视角范围更宽：FOV 支持 0–100°（0° 即正交极限，工具按正交出图并标注）， 俯角支持 0–90°（0° 平视 / 90° 纯顶视）；插件分别是 10–100° 与 5–90°。
  • 抗锯齿用 2× 超采样 + 盒式降采样近似插件里的 4× MSAA；像素风可关闭。
  • 纹理缩放一律最近邻：放大取 mip 0，不插值；缩小按 mip 层级取样（等价 NEAREST_WITH_MIPMAPS）， 只有可平铺角色最外圈 1px 会做接缝平均。
  • 描边拆成三套：内描边只覆盖该部件自己的像素（轮廓、折面断层、部件分界）； 部件外描边对每个部件各自向外扩，可以压到别的部件上；轮廓描边只把整栋剪影外扩到背景上。 插件是单一 outline，内外由同一个宽度隐式叠加。
  • 种子数值与 Godot 的随机序列不逐位对齐，但同一份配置在本工具内完全可复现。
  • 构建几何的代码逐条移植自插件脚本（v6 方言 + v5 主路径 + v4 原型建筑），参数、尺寸、层级一致。
  • 新增「部件检查器」：插件没有运行时拾取与部件级染色 / 换图；网页版在当前建筑上做覆盖，不动风格。

6. 输出

  • 导出当前方向：dir_0.png，透明或纯色背景，尺寸即画布尺寸。
  • 导出全部方向：ZIP 内含 dir_0.png … dir_N.png、sheet.png（默认横排，超过 16384 px 自动换行）与 recipe.json（完整配方，便于复现）。
  • 导出 Godot 预制体：ZIP 内含裁剪后的 PNG 与纯内置节点 .tscn（StaticBody2D + CollisionPolygon2D + Sprite2D + 遮挡层 Area2D），按你填写的 res:// 目录结构打包。碰撞层取地基在当前视角下的投影；遮挡层取不透明覆盖扣除碰撞区后、基点（地基中心）以上每块的外轮廓；不含脚本与 StippleShadow。预制体对应当前预览方向。
  • 目录名规则与插件一致：p<俯角>_<方向数>d[_persp<FOV>fov][_auto][_s<像素/米>ppm][_oi<内描边>-oo<外描边>[-os<轮廓描边>]]。
  • 图片内嵌参数（v1.1）：每张导出的 PNG 都写入工具版本与完整配方（PNG 文本块，像素不变）。用「导入图片配方」选一张本工具导出（或命令行 inspect 能读）的 PNG，即可恢复当时的风格、建筑、种子、参数、视角、描边与部件覆盖。
  • 部件贴图体积大，入图时会剥离，只保留来源与 crc32 指纹；导入后需要重新替换这些贴图。
  • 「下载图集模板」导出当前风格实际使用的 4×4 图集（512px，128/格），可直接交给画师重绘后再传回。
